## Notes on individual resources

- **T4 DNA ligase four-base overhang fidelity profile and NEBridge design tools:** Location and format of the raw overhang table not checked; read the supporting information before using it in a grader.
- **DNA Cauldron:** Candidate for outcome-aware grading: does the model's fragment and overhang choice assemble into the intended plasmid?
- **pydna:** Candidate check for colony PCR: do the primers amplify the intended product from the template?
- **AssemblyTron v0.0.8 archive:** Already recorded in sources/assemblytron/record.json.
- **Sequence-specific PCR amplification efficiency prediction (1D CNN):** Code and training-data location not checked.
- **PrimerCast:** Dataset size is from the conference abstract, not counted here.
- **LiqTransferOptimizer:** The closest public data on how accurately a robot delivers a commanded volume, which the Opentrons simulator does not model.
- **Opentrons/PhysicalAI:** No licence stated on the dataset card. Contents not inspected.
- **labos-sim/real_human_pipetting_lerobot_anonymized:** Real-world failure labels: relevant to physical faults a simulator cannot see.
- **AutoBio:** Models robot manipulation, not the biology. arXiv 2505.14030.
- **Pipette: embodied simulation platform and benchmark for wet-lab robotics:** Code location not found.
- **Source paper results: Evaluation of two automated low-cost RNA extraction protocols for SARS-CoV-2 detection:** Data-availability section and supporting files not opened. The task instruction gives this paper a different title; Crossref's is the one used here.
- **RNA extraction alternative method for SARS-CoV-2 molecular diagnosis:** Not the task's protocol; useful only as outcome data for the same kind of experiment.
- **Comparison of two RNA extraction methods for the molecular detection of SARS-CoV-2 from nasopharyngeal swab samples:** Not the task's protocol. The record exists but lists no public files (restricted or embargoed).
